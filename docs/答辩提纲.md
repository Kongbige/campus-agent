## 预判问题与回答要点

1. **“大模型在哪里体现？和规则机器人有什么区别？”** —— 大模型模式下由模型自主决定调用哪些工具、调用顺序和参数（展示轨迹中的“计划”）；离线模式只是为零密钥演示与容灾而设，泛化集评估结果说明了两者差距。
2. **“数据是真的吗？”** —— 地点、片区、食堂名称与到校交通来自官方鸟瞰图、学校官网和 OSM；部分坐标为估算并标注“待核实”，步行时间为直线估算；课表、活动等为示例数据，界面全程标注；获学校授权后替换 JSON 即可，无需改代码。
3. **“如何防止大模型胡编？”** —— 提示词规定事实必须来自工具；工具返回结构化数据；知识库答案注明来源；查不到如实告知。
4. **“报修真的能派单吗？”** —— 当前为原型，工单写入本地 SQLite，回答中已如实说明；后续可通过接口对接后勤系统。
5. **“成本与部署？”** —— 依赖 4 个包，普通笔记本可运行；国产模型按量计费，单次对话成本约几分钱（以各平台实际价格为准）；也可本地 Ollama 部署。
6. **“隐私安全？”** —— 不收集身份证/密码；电话为可选；提示词有越界拒绝与防注入规则。
7. **“为什么不做微调？”** —— 校园数据变化快，RAG + 工具调用更新成本低；积累数据后可对小模型做 LoRA 微调用于私有化。

## 现场演示应急预案
- 网络不可用 / 密钥失效：系统自动降级为离线模式，演示照常进行（可主动展示徽章与“已降级”提示，作为亮点）。
- 电脑故障：播放演示视频。
- 回答与预期不同：展开思考面板讲解智能体的决策过程。
