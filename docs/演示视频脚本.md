# 「城院小助手」演示视频脚本（约 4 分 30 秒）

> 要求：3-5 分钟。录屏工具：OBS / 剪映 / Windows 自带 Xbox Game Bar（Win+G）。分辨率 1920×1080，浏览器缩放 110%。
> **录制前准备**：
> 1. `.env` 中设置 `DEMO_TODAY=2026-11-02`（固定演示日期，保证课表/活动数据稳定）；如有密钥，配置大模型并确认徽章显示「🤖 大模型模式」，否则使用「🧩 离线演示模式」也可完整演示。
> 2. 删除 `data/runtime.db`，点击「开始新对话」，保证界面干净。
> 3. 准备手机（或 Chrome 开发者工具手机模拟）用于移动端镜头。
> 4. 旁白提前录好或现场配音，语速约每分钟 220 字。
