# 团队分工与进度计划

> 团队 3 人。以下为建议分工，可按成员特长调整。关键时间节点：**2026 年 11 月 13 日报名截止**，**2026 年 12 月 1 日作品提交截止**。

## 一、成员分工

| 成员 | 角色 | 主要职责 | 交付物 |
|---|---|---|---|
| **成员 A**（建议第一作者） | 后端与智能体 / 提示词 | 大模型接入与选型（DeepSeek/通义千问/智谱/Kimi 对比测试）；Agent 循环与工具调优；系统提示词与工具描述迭代；运行 `eval/evaluate.py --llm` 并记录结果；扩充评测用例 | 可运行代码、提示词版本记录、大模型模式评估结果 |
| **成员 B** | 前端界面 / 校园数据采集与替换 | 界面美化与移动端测试；**实地核实 `data/campus_map.json` 中标注“待核实”的坐标（医工楼、医科楼、西山会所、绿岛俱乐部及宿舍社区等）、片区归属与常用步行路线，核实公寓号与社区的对应关系**；收集食堂营业时间、活动、办事指南等公开信息，替换示例数据；拍摄校园照片 | 真实化的 data 目录、界面截图、校园素材 |
| **成员 C** | 设计文档 / 演示视频 / 答辩 | 开展问卷与访谈调研并整理数据；完善《设计文档》（补充调研数据、评估结果）并导出 Word；按《演示视频脚本》录制剪辑 3-5 分钟视频；制作答辩 PPT 并组织 2 次以上模拟答辩 | 设计文档.docx、演示视频、答辩 PPT |

**协作建议**：使用 Git（或共享网盘）管理代码与文档；每周固定 1 次 30 分钟例会；问题与待办记录在共享表格中。

## 二、进度计划（2026-10-26 至 2026-12-01）

| 阶段 | 时间 | 任务 | 负责人 |
|---|---|---|---|
| 启动 | 10/26（周一）-10/28 | 全员跑通项目（`pip install -r requirements.txt` → `python run.py`）；阅读设计文档；确定作品名称与第一作者；申请大模型 API Key | 全员 |
| 调研 | 10/27-11/05 | 发放问卷（目标 ≥100 份）、完成 5-8 人访谈；梳理现有服务入口 | C（B 协助） |
| 数据 | 10/29-11/10 | 实地核实待核实坐标与步行路线（更新 scripts/build_campus_map.py 并重新生成）；替换食堂营业时间/活动/知识库示例数据 | B |
| 模型 | 10/29-11/12 | 对比 2-3 个国产模型的工具调用效果；优化提示词；补充大模型模式评估数据 | A |
| **报名** | **11/10-11/13** | ⚠️ **填写并提交报名表，文件命名为：`2026年计算机应用大赛-第一作者姓名-作品名称-01`**（例：`2026年计算机应用大赛-张三-城院小助手-01`），按大赛通知要求的方式提交；**最晚 11 月 13 日**，建议 11/11 前完成以留余量 | C 负责填写，A 确认 |
| 迭代 | 11/13-11/22 | 根据调研结果调整功能优先级；邀请 10-20 名同学试用并收集满意度；修复问题；更新截图 | 全员 |
| 文档 | 11/16-11/25 | 定稿设计文档（补全调研与评估章节）并导出 Word；README 更新 | C（A 提供技术内容） |
| 视频 | 11/20-11/27 | 按脚本录制演示视频（固定 `DEMO_TODAY`），剪辑配音，控制在 3-5 分钟 | C（B 操作演示） |
| 提交 | 11/27-11/30 | 打包代码（**删除 .env 中的密钥**、删除 runtime.db）、设计文档、演示视频；全员检查一遍；**11/30 前提交，最晚 12 月 1 日** | A 打包，全员检查 |
| 答辩 | 12 月（以通知为准） | 制作 PPT，按《答辩提纲》控制在 8 分钟内，至少模拟 2 次 | C 主讲，A 演示，B 答疑 |

## 三、提交前检查清单

- [ ] 报名表已于 11 月 13 日前提交，文件名格式正确：`2026年计算机应用大赛-第一作者姓名-作品名称-01`
- [ ] 代码包可在一台全新 Windows 电脑上按 README 运行
- [ ] `.env` 不含 API Key（只提交 `.env.example`）
- [ ] 示例数据已替换或已明确标注“示例数据”
- [ ] 设计文档包含：场景分析、技术方案、提示词策略（及不微调说明）
- [ ] 演示视频 3-5 分钟，画面清晰、有旁白/字幕
- [ ] 答辩 PPT 不超过 8 分钟
- [ ] 作品材料于 12 月 1 日前提交

> 注：报名表与作品的具体提交方式、格式要求以大赛官方通知为准。
